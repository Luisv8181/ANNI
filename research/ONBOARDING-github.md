# ANNI GitHub guide — start here

You do **not** need to code or install anything to begin. Start in a web browser on any computer.

## Your first five minutes

1. Open the [ANNI project](https://github.com/Luisv8181/ANNI).
2. If GitHub asks you to sign in, create a free account at [github.com/signup](https://github.com/signup).
3. Open the [Research folder](https://github.com/Luisv8181/ANNI/tree/master/research).
4. Open the [source intake register](https://github.com/Luisv8181/ANNI/blob/master/research/sources/INTAKE-REGISTER.md).
5. Read the task message Luis sent you, then add only the work assigned to you.

## Four words you may see

- **Repository:** the shared ANNI project folder on GitHub.
- **Folder:** a group of files, like a folder on your computer.
- **Commit:** a saved change with a short description.
- **Push:** sending your saved change to the shared GitHub project. In the browser, GitHub does this when you choose **Commit changes**.

## Make one small browser edit

Only do this after Luis confirms you have edit access.

1. Open the file you were asked to change.
2. Click the pencil icon near the top-right of the file.
3. Make your small change.
4. Scroll to the bottom and write a short summary, such as `add source link for review`.
5. Click **Commit changes**.

If you do not see a pencil icon or GitHub says you cannot save, stop and ask Luis to add you as a collaborator. Do not make a second copy of the project or paste private material elsewhere.

## Optional: keep ANNI on your computer

You can use [GitHub Desktop](https://desktop.github.com/) on either Mac or Windows. After installing, sign in, choose **Clone a repository**, select `Luisv8181/ANNI`, and choose **Clone**. Use **Fetch origin** to get updates, then **Commit to main** and **Push origin** only after your change is ready.

You do not need Terminal. If you already use it, the optional command is `git clone https://github.com/Luisv8181/ANNI.git`.

## Research safety rules

- Add source **links first** to the intake register; do not paste raw testimony until license review is complete.
- Never upload real patient information, private identifiers, passwords, or API keys.
- If you cannot find a file, return to the [Research folder](https://github.com/Luisv8181/ANNI/tree/master/research) and use GitHub’s file search.
- If you are unsure whether a source can be used, leave it as a link and ask Luis or Heath before adding text.

# Start here — ANNI team workspace

Welcome. ANNI is a shared research workspace. You can start in a browser; no coding experience is expected.

## Open these links in order

1. [ANNI project](https://github.com/Luisv8181/ANNI)
2. [Research folder](https://github.com/Luisv8181/ANNI/tree/master/research)
3. [Source intake register](https://github.com/Luisv8181/ANNI/blob/master/research/sources/INTAKE-REGISTER.md)
4. [Beginner GitHub guide](https://github.com/Luisv8181/ANNI/blob/master/research/ONBOARDING-github.md)

## If you need an account

Create a free GitHub account at [github.com/signup](https://github.com/signup). Tell Luis the username you chose so he can give editing access if your role needs it.

## If something goes wrong

- **I cannot open ANNI:** check the first link above, then message Luis with a screenshot of the error.
- **I can read but cannot edit:** this means you need collaborator access; ask Luis rather than creating a duplicate.
- **I cannot find my task:** open the Research folder and ask Luis which file to open.
- **I am unsure about a source:** add only its link to the intake register and ask for license review.
